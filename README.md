# BACS_profiles_scripts
This repository contains the scripts used for analysis and figures for the manuscript _What Controls Variability in Cold Pool Thermodynamic Vertical Structure?_

The sfc_CP_identification.ipynb file identifies CP passage times and surface relative changes associated with each cold pool to create a table. The sfc_CP_cluster_characterization_to_table.ipynb file takes that table after additional information  is added to it, and creates a new table that pairs each profile with information relevant to it. The rest of the scripts are labeled by what figure it produces.
